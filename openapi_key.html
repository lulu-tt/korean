신청 전 확인
· 로그인한 회원 계정으로 발급됩니다. (프로토타입: hanguk_user)
· 사용 URL은 API를 연동할 웹사이트·앱 서버 주소를 입력합니다.
· 발급된 키는 외부에 공개되지 않도록 안전하게 관리해 주세요.
Open API 인증키 발급 신청

지역어 Open API를 호출할 사이트 또는 개발 환경 주소를 입력해 주세요. (필수)
선택 사항입니다. 관리·문의 시 참고용으로 사용됩니다.
02

이용 유의사항

  • 인증키(apiKey)는 모든 Open API 요청에 필수입니다.
  • 요청 URL 예: https://dialect.korean.go.kr/dialect/openAPI/data
  • 과도한 호출은 서비스 안정성을 해칠 수 있으니 필요 범위 내에서 이용해 주세요.
  • 키 분실·유출이 의심되면 즉시 재발급하고, 기존 연동 설정을 갱신해 주세요.
  • 상세 요청 변수·응답 필드는 활용안내를 참고하세요.
