# 개발서버 테스트 결과서 (2026-10-16)

결과서 원본은 구글 시트 «국립국어원_요구사항정의서»의 아래 4개 탭에 있다.

| 탭 | 내용 |
|---|---|
| 개발서버 단위테스트(사용자) / (관리자) | 화면 접속·목록 표시 점검 (15 / 22개 화면, 읽기 전용) |
| 개발서버 기능테스트(사용자) | 기존 사이트(운영개발 미러) 대비 데이터 비교, 회원가입, 질의응답, 지도 그리기 |
| 개발서버 기능테스트(관리자) | 게시판·조사 자료·지도 화면의 등록·수정·삭제 |

## 파일

- `gen_report.py` — 단위테스트 CSV 생성 (`test_report_user.csv`, `test_report_admin.csv`)
- `gen_functional*.py` — 기능테스트 CSV 생성 (`functional_*.csv`)
- CSV는 `.gitignore`(`*.csv`)라 커밋되지 않는다. 스크립트를 다시 돌리면 만들어진다.

## 관련 테스트 코드 (`tests/`)

- `tests/test_devserver.py` — 로컬 `dev.py`(8765·8877) 읽기 전용 스모크 테스트
- `tests/test_remote_dev.py` — 원격 개발서버 비로그인 점검(+`DEV_COOKIE` 지정 시 관리자, 다만 브라우저 외 호출은 «비정상 접근»으로 거부될 수 있음)
- `tests/compare/compare_boards.py` — 개발서버·미러 게시판 목록 대조

## 남은 항목

- 구술발화 등록 저장·수정·삭제: 시험용 제보자가 필요(실제 제보자 연결 위험으로 중단)
- 지역어 기상도 엑셀 업로드, 사용자·제보자 관리, 일괄등록, 회원가입 오류 입력 시험
