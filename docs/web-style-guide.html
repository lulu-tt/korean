06 / BEHAVIOR

Motion & accessibility

움직임은 사용자의 맥락을 보조할 때만 씁니다. 자동 전환을 멈출 수 있고, 모션 감소 환경에서는 장식 동작을 최소화합니다.

Short transitions

색상, 테두리, 화살표 변화 중심

Reduced motion

자동 회전과 스크롤 모션 해제

Keyboard control

슬라이드 정지·이동과 포커스 제공

07 / PRINCIPLES

Design principles

화면을 만들거나 고칠 때 다음 기준으로 일관성과 접근성을 확인합니다.

DO권장합니다

  • 카드보다 여백과 선으로 정보 구조를 만듭니다.
  • 실제 지역어와 조사 정보를 화면의 중심에 둡니다.
  • 본문 텍스트는 14px 이상으로 읽기 쉽게 제공합니다.
  • 수치에 단위, 기준 시점, 출처를 함께 표시합니다.
  • 새 스타일은 페이지 루트 아래로 범위를 한정합니다.

AVOID피합니다

  • 장식용 카드, 그림자, 둥근 모서리를 반복하지 않습니다.
  • 정보를 이미지나 색만으로 전달하지 않습니다.
  • 멈춤 기능 없는 자동 슬라이드를 사용하지 않습니다.
  • 기존 GNB/Footer를 확인하지 않고 전역 CSS를 덮어쓰지 않습니다.
  • 서로 다른 시기의 화면 규칙을 구분 없이 혼합하지 않습니다.
