03 / CONTENT HIERARCHY

Bullet system

제목과 목록의 단계에 따라 크기와 불릿 모양을 달리해 긴 설명도 쉽게 훑어볼 수 있게 합니다.

데이터 공유 · 개방 확대

공공데이터란 데이터베이스, 전자화된 파일 등 공공기관이 법령 등에서 정하는 목적을 위하여 생성 또는 취득하여 관리 중인 공 또는 전자적 방식으로 처리된 자료 또는 정보를 말합니다.

  • 고용 · 노동 DW 및 고용노동데이터분석시스템(ELDS) 구축으로 데이터 공유 · 개방 확대
    • 공공데이터 포털(data.go.kr)을 통해 총 82종 개방
    • 신규 개방 건수: 13종(2021년) → 33종(2022년) → 36종(2023년)
  • 공공데이터 제공 안내
    • 공공데이터 제공이란 공공기관이 이용자에게 기계 판독이 가능한 형태의 데이터를 접근할 수 있도록 제공하는 것을 말합니다.
    • 제공 목적과 활용 범위가 분명히 드러나도록 제목, 설명, 목록 단계를 구분합니다.
