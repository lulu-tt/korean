# 지역어 종합 정보 v4 디자인 노트

## 방향

v4는 밝고 현대적인 지역어 디지털 아카이브를 목표로 한다. 생성형 3D 이미지, 둥근 카드, 작은 영문 분류와 화살표를 반복하던 랜딩 페이지 문법을 줄이고 문서 편집물과 공공 데이터 서비스의 인상을 결합했다.

## 주요 원칙

- GNB와 Footer 공통 파일은 수정하지 않는다.
- 제목과 본문은 Pretendard 기반 시스템 글꼴 스택으로 통일하고 굵기와 크기로 위계를 구분한다.
- 카드보다 선, 여백, 타이포그래피로 정보 구조를 만든다.
- GPT Image 결과는 히어로와 기록 콘텐츠에만 사용한다.
- 조사 수치와 지역별 표현처럼 실제 정보가 화면의 중심이 되게 한다.
- v3의 오늘의 지역어·퀴즈와 생활어 사진 자료를 가져오되, 자동 회전 카드와 사회관계망 피드 형식 대신 한 화면에서 읽히는 편집형 구성으로 재해석한다.
- v3의 서비스 체계를 참고해 나만의 지도와 지역어 자료실 진입점을 보강한다.
- 자료 탐색 영역은 매쓰플랫의 3열 솔루션 카드 구조와 호버 반응을 참고하되, 직선적인 테두리와 기록물 이미지, 큰 한글 타이포그래피로 공공 아카이브의 인상을 유지한다.
- 지역어 분포 미리보기는 다른 자료 탐색 기능과 역할이 겹쳐 제거하고, 오늘의 지역어와 생활어 기록 사이를 밝은 배경과 얇은 구분선으로 연결한다.
- 본문 영역의 모든 표시 글자는 14px 이상으로 유지한다.
- 자동 슬라이드, 단어 전환, 퀴즈, 카운트 애니메이션은 키보드와 모션 감소 설정을 지원한다.
- 히어로, 지도, 생활어 사진, 기록 이미지에는 서로 다른 깊이의 패럴랙스를 적용한다. 760px 이하 화면과 모션 감소 환경에서는 효과를 자동으로 해제한다.
- 페이지 마지막의 Open API 영역은 설명과 두 개의 분명한 진입 경로로 구성하며, v4에서만 공통 Footer 상단의 60px 여백을 제거해 두 영역을 바로 연결한다.

## 파일

- `index_v4.html`: 페이지 구조와 콘텐츠
- `index_v4.css`: 편집형 레이아웃과 반응형 디자인
- `index_v4.js`: 히어로 슬라이드, 단어 전환, 카운트, 절제된 스크롤 효과
- `assets/renewal-v4/`: GPT Image 생성 원본 PNG와 최적화 WebP
