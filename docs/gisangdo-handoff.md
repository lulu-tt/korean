>
> 기존 개발분을 고치든 새로 만들든 **같은 결과가 나오게** 하려고 쓴 문서다.

> 참고 구현의 파일 위치, 시연 배포, 데이터 현황은 부록에 따로 두었다.

## 0. 한눈에

```
원자료 엑셀 (제보자 1명 = 파일 1개)
   │  관리자 › 업로드 (사전 점검 → 적재)
   ▼
DB  wb_weather_file · wb_weather_response · wb_weather_adjust(보정)
   │  판정 함수 하나 (§5)
   ▼
결과 JSON  항목 100개(목록 101개 중 숨김 1) × 지역 9곳
   ├─▶ 관리자 화면 (항목 목록 · 응답 관리 · 보정)
   └─▶ 사용자 화면 (기상도 지도)
```

지켜야 할 원칙 세 가지
1. **판정 규칙은 한 곳에만** 둔다. 관리자·사용자 화면이 같은 함수를 부른다.
2. **원본 응답은 고치지 않는다.** 사람의 판단은 보정 표(§6)에만 적는다.
3. 판정은 **요청할 때마다 DB에서 다시** 계산한다. 결과를 미리 구워 두려면 DB가 바뀌었는지 확인하고 써야 한다.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 항목번호 | 5자리 단어 번호. 예: `21105` = 호미 |
| 하위코드 | `-A-n` = **방언형**("이것도 아세요?" 하고 제시해서 물은 변이형). `-B-n` = **표준어와 같은 방언형**(그 지역 방언형이 표준어와 글자가 같은 것). 둘 다 지도에 반영한다(2026-10-26 담당자 정의) |
| 표제어 | 그 줄에서 **물은 말**. 하위코드 없는 줄은 표준어(호미), 하위코드 줄은 제시한 변이형(호맹이) |
| 대표 표제어 | 한 항목에서 가장 많이 적힌 표제어 = 보통 그 항목의 표준어. 지도의 단어 이름 |
| 방언형(기저형) | 제보자가 **실제로 말한 것**. 비었거나 `*`면 말하지 않음 |
| 지역어형 | 대표 표제어와 다른 말. 판정에는 **지역어형에 붙은 등급만** 쓴다 |
| 등급 | 사용도/인지도. 1 지금도 씀 · 2 써 봤으나 안 씀 · 3 들어 봄 · 4 처음 들음 |
| 제보자 | 파일 하나 = 사람 하나. 파일명 앞 9자리(`CB2570FVE`)가 식별자 |
| 연차 | 조사 사업 회차. 파일명의 두 자리(`25`) |

화면 문구에는 '표준어형'·'표제어'·'표제어형' 대신 **'조사어휘'**를 쓴다(2026-10-19). 이 문서는 설명의 편의상 '표제어'라고 부른다.

## 2. 원자료 서식 (2025 새 서식)

### 2.1 파일

- 파일명 `{지역2}{연차2}{세대2}{성별1}VE_사용도인지도.xlsx`. 예: `CB2570FVE_…` = 충북 · 25차 · 70대 · 여
  - 지역 GG 경기 · GW 강원 · CB 충북 · CN 충남 · JB 전북 · JN 전남 · GB 경북 · GN 경남 · JJ 제주
  - 세대 20 · 50 · 70, 성별 F 여 · M 남
  - 앞 9자리가 같으면 같은 사람이다. 뒤 꼬리는 없거나 달라도 된다.
- 2025년 설계는 51명이다(제주 등 일부 지역은 6명이 아니다). 미수령 4명은 부록 B.
- **첫 시트만** 읽는다.

### 2.2 열

| 열 | 머리글 | 규칙 |
|---|---|---|
| A | 제보자 | 파일명 앞 9자리와 다르면 파일째 거부 |
| B | 일련번호 | `제보자+항목번호`. 판정에는 안 쓴다 |
| C | 항목번호 | `21105` 또는 `21105-A-1` |
| D | 표준어형 · 표제어 | 머리글 이름이 파일마다 다르다(§2.4) |
| E | 방언형(기저형) | 비거나 `*` = 말하지 않음 |
| F | 사용도/인지도 | 1~4. 전각 `１`은 반각으로 |

### 2.3 담당자와 정한 정리 방침

1. **등급이 없는 줄은 원자료에서 뺀다.** 없는 줄을 '빠졌다'고 다시 요청하지 않는다.
2. 같은 제시어의 구술 변이를 하위코드로 나눠 적는 것은 정상이다.
3. 한 제보자 안에서 **서로 다른 제시어가 같은 하위코드**면, 뒤 줄을 다음 빈 번호로 옮긴다(`-A-1` → `-A-2`).
4. 괄호 주석은 붙인다: 회충(蛔蟲) · 가(邊) · 새끼(繩) · 키(箕) · 할머니(호칭) · 형(호칭) · 사위(호칭).
5. 표준어가 둘이면 `서 되/세 되`처럼 `/`로 잇는다.

### 2.4 읽을 때 처리할 것

| 상황 | 처리 |
|---|---|
| 머리글 이름이 다름 | 공백과 꼬리 `(수정)·(보충)·(최종)·(검수)`를 떼고 별칭으로 모은다. 표제어 칸: `표제어 · 표제어형 · 표준어형 · 대응표준어`. 등급 칸: `사용도/인지도 · 인지도/사용도` |
| 칸이 엑셀 수식 | 일련번호(`=A2&C2`)나 항목번호가 수식인 파일이 있다. **엑셀이 저장해 둔 결과값**을 읽는다 |
| 한글 파일명 | macOS 파일명은 자모 분리형(NFD)이다. 비교하기 전에 NFC로 맞춘다 |
| `~$`로 시작하는 파일 | 엑셀 잠금 파일이다. 건너뛴다 |
| 중간 빈 줄 | 건너뛴다. 사람에게 행을 알릴 때는 **실제 엑셀 행 번호**를 쓴다 |

## 3. DB 표

```sql
-- 제보자 파일 (1행 = 1명)
CREATE TABLE wb_weather_file (
  weather_file_id INTEGER PRIMARY KEY,
  file_nm TEXT NOT NULL UNIQUE,     -- 제보자 열쇠 'CB2570FVE.xlsx' (원래 파일명 아님)
  region_cd TEXT NOT NULL, region_nm TEXT,
  research_year INTEGER,            -- 2025
  research_degree TEXT,             -- '25' ← 연차 필터
  generation INTEGER, sex TEXT,     -- 20/50/70, F/M
  row_cnt INTEGER, item_cnt INTEGER, src_layout TEXT,
  use_yn TEXT DEFAULT 'Y', reg_id TEXT, reg_dt TEXT, upt_id TEXT, upt_dt TEXT);

-- 응답 (1행 = 엑셀 1줄)
CREATE TABLE wb_weather_response (
  response_id INTEGER PRIMARY KEY,
  weather_file_id INTEGER NOT NULL REFERENCES wb_weather_file,
  line_no INTEGER NOT NULL, serial_no TEXT,
  item_cd TEXT NOT NULL,            -- '21105-A-1'
  item_base TEXT,                   -- '21105' ← 판정은 이 값으로 묶는다
  headword TEXT,                    -- 표제어
  dialect_form TEXT,                -- 방언형(기저형)
  grade TEXT,                       -- 원문 그대로
  grade_valid_yn TEXT DEFAULT 'N',  -- 1~4면 'Y'
  use_yn TEXT DEFAULT 'Y', reg_dt TEXT, upt_dt TEXT);

-- 보정 (§6)
CREATE TABLE wb_weather_adjust (
  file_nm TEXT NOT NULL,            -- 제보자 열쇠
  item_base TEXT NOT NULL,
  grade TEXT NOT NULL,              -- '1'~'4' 또는 'X'(이 항목에서 제외)
  src_sig TEXT,                     -- 보정할 때 본 응답 'dialect_form/grade|…'
  reg_dt TEXT, upt_dt TEXT,
  PRIMARY KEY (file_nm, item_base));
```

- 시각은 모두 **한국 시각(KST)**으로 저장한다.

## 4. 업로드와 삭제 (관리자)

**올리기 전 점검** (화면에서)

| 결과 | 조건 |
|---|---|
| 중단 | 파일명 규칙 위반 · 9개 지역이 아닌 코드 · **보정이 걸린 제보자를 덮어씀** |
| 경고 | 잠금 파일 제외 · 같은 제보자 파일 중복 · 이미 올라간 제보자(덮어씀) · 자료가 없는 지역이 남음(그 지역은 '관측 없음') |

**서버 적재** (파일마다)

| 결과 | 조건 |
|---|---|
| 거부 | 파일명·지역코드 이상 · 읽기 실패 · 항목번호 있는 줄 없음 · **제보자 칸 ≠ 파일명** |
| 받고 경고 | 표제어 칸에 하위코드가 섞임(`반짇그릇-A-1`) · 서비스 목록(§5.1)에 없는 항목번호(대개 오타) · 다른 시트에 값이 남음 |
| 집계 | 등급이 1~4가 아닌 줄 수 (빈칸·`*` 제외) |

- **재업로드**: 같은 제보자(앞 9자리)면 기존 줄을 지우고 다시 넣는다. **보정은 유지한다.**
- **삭제**: 그 제보자의 응답과 **보정까지** 지운다.
- **B 대조**: 적재가 끝나면 올린 지역·연차의 줄 전체를 기준표와 대조해, B가 있는데 기준표상 그 지역 방언형이 표준어와 다르면(B 지역 아님) 경고한다. 비교는 글자 그대로(공백만 무시). B가 없는 것은 제보자가 그렇게 답하지 않은 것이라 정상이므로 경고하지 않는다. 지도에 내지 않는 항목(hidden)은 대조하지 않는다.
- 항목번호가 빈 줄은 버린다.

## 5. 판정 규칙 ★

### 5.1 어떤 항목을 보여 주나

- **서비스 목록**(`gisangdo_service_items.json`, 101개)에 있고, 어느 지역에서든 등급이 하나라도 있는 항목만 보여 준다.
- 자료가 없는 지역이 있어도 항목은 빼지 않는다. 그 지역만 '관측 없음'이 된다.
- 목록에 `"hidden": true`인 항목은 업로드는 받되 지도에 내지 않는다. 지금은 22602 다르다/틀리다("다르다"를 쓸 자리에 두 말 중 무엇을 쓰는지 묻는 항목이라 특성이 다름). 그래서 지도 항목은 100개다.
- 항목을 더하거나 뺄 때는 이 목록 파일을 고친다. 사용자 화면의 범주(항목번호 앞 3자리 → 범주)에 없는 번호대면 '기타'로 묶인다.

### 5.2 한 줄이 지역어형인지

- 그 줄의 말 = 방언형이 있으면(`*` 제외) 방언형, 없으면 표제어
- **`-B-n` 줄은 항상 지역어형**으로 센다. 글자가 표준어와 같아도 그 지역 방언형이기 때문이다.
- 그 밖의 줄은 그 말이 **대표 표제어와 같으면 표준어, 다르면 지역어형**이다. 비교 전에 다음을 맞춘다.
  - 공백과 괄호 안을 지운다: `할머니(호칭)` → `할머니`
  - `/`로 나눈 것은 모두 표준어다: `서 되/세 되` → `서되`, `세되`
- 예: 호미 항목에서 '호미'는 표준어, '호맹이' · '호밋가루'는 지역어형이다. 경기 입술의 `20116-B-1 입술/입술/1`은 지역어형 ①로 센다.
- 이 규칙은 `counts_as_dialect()` 한 함수에 있고, 판정·관리자 응답 API·배포 응답 API가 모두 이 함수를 부른다.
- 단어 이름은 대표 표제어를 쓴다. 단, 별칭 표가 있으면 그것을 따른다(예: `가` → `가(邊)`).

### 5.3 제보자 → 지역 → 날씨

1. **제보자 대표 등급** = 그 항목에서 그 사람이 지역어형에 준 등급 중 **가장 좋은 값**(가장 작은 수). 보정이 있으면 보정값을 쓴다.
   - **2026-10-13 현업 결정으로 확정**: 평균이 아니라 가장 높은 점수를 쓴다. 평균을 쓰면, 지역어를 쓰는 사람도 조사원이 들려준 낯선 변이형을 모른다고 답한 만큼 점수가 깎인다(예: 충북 귀이개 50대 남 — 귀후비개 ①, 귀개 ③, 구레쉬엄 ④ → 평균 58점). 엉뚱한 말이 뽑히는 칸은 보정(§6)으로 바로잡는다.
2. **점수**: 1=100 · 2=75 · 3=50 · 4=25
3. **지역 점수** = 대표 등급이 있는 제보자들의 점수 **평균**
   - 표제어(표준어)로만 답한 사람과, 지역어형에 등급이 없는 사람은 평균에서 빠진다.
   - 그래서 평균에 든 인원(`n`)은 항목마다 다를 수 있다.
4. **날씨**

| 상태 | 조건 | 화면 라벨 |
|---|---|---|
| `w1` | 87.5 이상 | 맑음 |
| `w2` | 62.5 이상 | 구름조금 |
| `w3` | 37.5 이상 | 흐리고 비 |
| `w4` | 37.5 미만 | 천둥번개 |
| `std` | 줄은 있는데 모두 표준어로 답함 | 지역어형 없음 |
| `w0` | 줄이 없거나, 지역어형은 있는데 등급이 없음 | 관측 없음 |

- 구간 경계는 등급 사이 중간값이다(1.5 · 2.5 · 3.5 등급에 해당).
- **세대 칸, 세대×성별 칸**도 같은 방식으로 계산한다.
- **'전체' 단어(지도 항목 전부를 합친 통합 지도)**: 그 지역의 (제보자, 항목) 짝마다 대표 등급을 하나씩 모아 같은 방식으로 평균한다.

## 6. 보정

- 담당자가 **제보자 × 항목** 단위로 대표 등급을 바꾼다. 값은 `1~4` 또는 `X`(그 사람을 이 항목에서 뺌)이고, 빈 값이면 해제한다.
- 원본은 두고 보정 표에만 저장한다. 재업로드해도 남고, 파일을 삭제하면 함께 지워진다.
- 보정할 때 본 응답(`src_sig`)을 같이 저장한다. 원본이 바뀌면 "다시 확인"을 띄울 수 있다.
- 사유 칸은 두지 않는다.

## 7. 연차와 '전체'

- 연차는 `research_degree`로 거른다. `year=latest`는 서버가 가장 최근 연차로 바꿔 준다. `year=`(빈 값)는 전체다.
- 사용자 화면에는 연차 칩 **[전체] [2024년] [2025년]…**을 두고, 기본값은 가장 최근 연차다. 관리자 목록에도 연차 필터와 연도 칸이 있다.
- **'전체'는 연차별 결과를 더하지 않는다.** 모든 연차의 응답을 모아 §5를 다시 계산한다.
  - 제보자가 많은 연차가 더 크게 반영된다.
  - 같은 사람이 두 해 모두 조사됐어도 두 명으로 센다. 파일명에 연차가 들어가기 때문이다.
  - 예: 어느 지역에 25차 6명(평균 75점)과 24차 6명(평균 25점)이 있으면, 전체는 12명 평균 50점(흐리고 비)이다.

## 8. API

**관리자** (`/mariadb/neibis-api/weather/…`) — 운영에서는 **관리자 권한 확인이 필요하다**(참고 구현에는 없음).

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| POST | `upload` (multipart `files`) | §4 적재. `results` · `issues` · `warnings` · `message` |
| GET | `awareness?year=` | §5.4 결과 |
| GET | `files` | 제보자 파일 목록. 보정 수 `editedCnt` 포함 |
| GET | `responses?item=21105` | 한 항목의 응답 줄 전부 + 제보자별 계산값·보정값 |
| POST | `adjust` `{item, rows:[{file, grade}]}` | 보정 저장. `grade:''`면 해제 |
| POST | `delete` `{id}` 또는 `{ids}` | 제보자 파일 삭제(응답·보정 포함) |

**사용자**: GET `/api/weather/awareness?year=latest|25|` (읽기 전용)
- 실패하면 지도 전체를 '관측 없음'으로 그린다. 추정값이나 예전 파일로 채우지 않는다.
