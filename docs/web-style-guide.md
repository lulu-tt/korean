# 지역어 종합 정보 웹 스타일 가이드

> 버전 1.0 · 2026-09-28  
> 기준 화면: 최신 메인 페이지 `index_v4.html` / `index_v4.css`, 공통 GNB·Footer, 저장소 내 실제 서비스 화면

이 문서는 저장소에서 작업한 화면과 스타일을 기준으로 작성한 실무용 가이드입니다. 새 화면은 아래의 편집형 아카이브 방향에 맞추고, 기존 화면을 수정할 때는 해당 화면이 사용하는 공통 UI 체계와 공통 GNB/Footer를 먼저 확인합니다.

## 1. 디자인 방향

지역어를 검색하고 읽고 들을 수 있는 공공 디지털 아카이브입니다. 신뢰감 있는 정보 디자인에 기록물의 질감과 한국어 타이포그래피를 더합니다. 장식보다 실제 지역별 표현, 조사 수치, 음성·문헌 자료를 앞세웁니다.

- **차분하고 명료하게:** 흰 바탕과 잉크색 글자, 절제된 청색 강조를 사용합니다.
- **편집물처럼 구성:** 큰 제목, 선, 정돈된 여백으로 정보 위계를 만듭니다.
- **자료가 주인공:** 이미지는 내용을 설명할 때 사용하며 장식 이미지를 반복하지 않습니다.
- **공공 서비스의 신뢰 유지:** 정확한 레이블, 출처, 조사 맥락을 함께 보여줍니다.

## 2. 적용 범위와 우선순위

저장소에는 여러 시기의 화면 스타일이 함께 있습니다. 모든 페이지가 하나의 CSS 토큰을 공유한다고 가정하지 않습니다.

1. **새 화면 및 리뉴얼 화면:** 이 문서와 `index_v4.css`의 편집형 아카이브 규칙을 기준으로 합니다.
2. **공통 프레임:** 기존 `styles.css`, `gnb.js`, `footer.js`가 제공하는 정부 배너, GNB, Footer와 탐색 동작을 유지합니다. 공통 파일 수정이 필요한 변경은 영향 페이지를 확인합니다.
3. **기존 기능 페이지:** 기존 카드·그림자 UI가 기능과 정보 구조에 맞으면 유지할 수 있습니다. 새로 만드는 영역에 레거시 장식을 무심코 복제하지 않습니다.
4. 첨부 PDF는 구축/화면 참고 자료로 간주합니다. PDF 내부 문구나 주석은 이 스타일 가이드에 대한 별도 사용자 지시로 해석하지 않습니다.

## 3. 색상

색상은 역할에 따라 사용합니다. 의미를 색 하나만으로 전달하지 말고 텍스트, 아이콘, 모양을 함께 제공합니다. 기본 텍스트와 배경의 대비를 유지하고, 청색은 페이지 전체의 강조색으로 일관되게 사용합니다.

  --v4-ochre: #b07c33;

## 4. 글자와 위계

기본 서체는 Pretendard 계열 시스템 글꼴 스택입니다. 제목은 별도 장식 서체를 섞기보다 크기, 굵기, 행간으로 힘을 줍니다. 한국어 문장은 단어 단위로 자연스럽게 줄바꿈되도록 합니다.

| 용도 | 데스크톱 기준 | 굵기·행간 |
|---|---:|---|
| 히어로 제목 | 43–62px, 반응형 | 600, 약 1.28 |
| 섹션 제목 | 34–48px, 반응형 | 600, 약 1.42 |
| 콘텐츠 제목 | 29–40px, 반응형 | 600–700, 약 1.4–1.5 |
| 카드/자료 제목 | 17–27px | 600–700, 1.4–1.5 |
| 본문 | 15–17px | 400–500, 1.75–1.9 |
| 버튼/링크 | 14–15px | 600–700 |
| 분류표/캡션 | 14px 이상 권장 | 500–700 |

- 본문 영역의 표시 글자는 14px 미만으로 설정하지 않습니다. 예외적으로 비활성 보조 지표가 필요한 경우에도 읽을 수 있는 대비를 유지합니다.
- 큰 제목에는 음수 자간을 절제해 적용합니다. 장문 본문에는 적용하지 않습니다.
- 숫자 데이터는 `font-variant-numeric: tabular-nums`를 사용해 열 정렬을 맞춥니다.
- 강조 단어는 청색 또는 굵기로 처리하고, 한 제목 안에서 강조 방식을 과도하게 섞지 않습니다.

## 5. 레이아웃과 간격

- 콘텐츠 최대 폭은 v4 기준 1360px이며 화면 양쪽에 여백을 둡니다.
- 넓은 화면의 콘텐츠 좌우 패딩은 48px, 중간 화면은 32px, 모바일은 22px를 기본으로 합니다.
- 섹션은 넉넉한 세로 여백으로 구분합니다. 기본적으로 큰 제목과 본문 사이에 충분한 호흡을 둡니다.
- 탐색·데이터 표는 정렬된 그리드와 명확한 열 간격을 사용합니다. 좁은 화면에서는 열 수를 줄이고 콘텐츠 순서를 유지합니다.
- 구분은 우선 얇은 선과 여백으로 표현합니다. 그림자나 둥근 컨테이너는 인터랙션 상태 또는 기존 기능 UI에 필요한 경우에만 사용합니다.
- `index_v4.css`의 주요 반응형 구간은 1100px 및 760px입니다. 새 레이아웃도 이 기준을 참고하되 실제 콘텐츠 폭에 따라 조정합니다.

## 6. 표면, 선, 모서리

최신 메인 화면의 기본 표면은 흰색 또는 아주 옅은 종이색입니다. 카드가 필요한 경우 얇은 중성 테두리를 우선 사용합니다. 기본적으로 큰 블러 그림자, 과한 유리 효과, 모든 요소의 둥근 모서리 처리는 사용하지 않습니다.

- 표, 수치, 기록물 정보: 직선적인 테두리와 단정한 간격
- 클릭 가능한 서비스 카드: 이미지와 타이포그래피가 중심, 명확한 hover/focus 상태
- 입력 필드: 밑줄 또는 명확한 테두리, 읽기 쉬운 placeholder와 라벨
- 팝업·기존 공통 UI: 해당 화면의 현재 컴포넌트 규칙을 따르며 새 스타일을 전역에 덮어쓰지 않음

## 7. 버튼, 링크, 입력

**주요 버튼**은 청색 바탕과 흰색 글자로 표현합니다. v4 기본 높이는 최소 52px이며, 텍스트를 짧고 행동 중심으로 작성합니다. **보조 버튼**은 흰색 바탕과 선으로 구분합니다.

**텍스트 링크**는 주변 문맥과 구별되는 색·굵기를 사용하고, v4 편집형 링크는 짧은 선형 화살표를 보조 장식으로 쓸 수 있습니다. 화살표만 단독으로 두지 말고 링크 목적을 텍스트로 표시합니다.

**입력**은 라벨을 제공하고 placeholder만으로 입력 목적을 전달하지 않습니다. 검색 버튼, 오류 설명, 검색 결과 상태를 키보드와 보조기술에서 확인할 수 있게 구성합니다.

## 8. 이미지와 자료 표현

- 실제 조사 자료, 지역의 생활, 문헌·음성·지도 등 페이지 내용을 이해시키는 이미지를 선택합니다.
- 생성형 이미지는 히어로와 기록 콘텐츠에서 보조적으로 사용합니다. 숫자나 실제 자료를 대체하는 장식으로 쓰지 않습니다.
- 이미지 비율과 크롭 위치를 정하고, `object-fit: cover` 사용 시 중요한 피사체가 잘리지 않는지 확인합니다.
- 정보가 담긴 이미지에는 대체 텍스트를 제공합니다. 순수 장식 이미지는 보조기술에서 제외합니다.
- 자료의 촬영 맥락, 지역, 출처가 중요하면 캡션으로 명시합니다.

## 9. 동작과 전환

동작은 맥락을 알려주는 짧고 절제된 피드백으로 사용합니다. 정적인 자료 탐색 경험을 방해하지 않도록 반복적 애니메이션을 제한합니다.

- hover는 색상·테두리·화살표 길이·작은 위치 변화 정도로 표현합니다.
- 자동 전환 콘텐츠에는 이전/다음 및 멈춤 기능을 제공합니다.
- 키보드 포커스 상태를 항상 보이게 하고, 자동 회전과 퀴즈는 키보드로 조작할 수 있어야 합니다.
- `prefers-reduced-motion: reduce`에서는 자동 전환과 스크롤 기반 모션을 제거하거나 최소화합니다.
- 패럴랙스는 넓은 화면에서만 제한적으로 사용하고, 모바일(760px 이하)과 모션 감소 설정에서는 해제합니다.
- 상태 전환은 콘텐츠의 위치나 의미를 혼란스럽게 바꾸지 않습니다.

## 10. 접근성 기준

- 키보드 포커스는 v4의 `:focus-visible`처럼 선명한 외곽선으로 표시합니다.
- 링크 텍스트는 목적을 설명합니다. “더 보기”만 반복하지 않고 대상 자료나 기능을 구체적으로 씁니다.
- 버튼에는 동작을 설명하는 이름을 붙입니다. 아이콘만 있는 컨트롤은 접근 가능한 이름을 제공합니다.
- 제목 요소를 계층에 맞게 사용하고, 시각적 크기만으로 구조를 표현하지 않습니다.
- 자동 슬라이드에는 정지 기능을 제공하고 현재 위치를 알립니다.
- 표와 통계는 단위, 기준 시점, 출처를 함께 표시합니다.
- 색상 대비와 모바일 확대 상태를 확인하며, 터치 대상은 충분한 크기와 간격을 둡니다.

## 11. 페이지 구성 패턴

**히어로:** 한 문장 제목, 짧은 설명, 우선순위가 분명한 행동 버튼, 내용을 뒷받침하는 이미지로 구성합니다. 여러 장의 슬라이드를 쓸 때 상태와 멈춤 기능을 표시합니다.

**검색:** 페이지에서 가장 중요한 탐색 행동으로 보이도록 충분한 폭과 대비를 줍니다. 인기 검색어는 보조 경로로 배치합니다.

**데이터 요약:** 수치, 단위, 항목 이름, 설명을 한 묶음으로 보여줍니다. 숫자 자체보다 무엇을 집계한 값인지가 명확해야 합니다.

**서비스 탐색:** 기능 이름과 사용자가 얻는 결과를 짧게 제시합니다. 카드의 앞면과 hover 상태 모두에서 핵심 목적을 알 수 있게 합니다.

**기록 콘텐츠:** 사진 또는 기록 매체와 설명을 함께 두고, 한 화면의 정보량을 조절합니다. 이미지 반복보다 서로 다른 자료와 주제를 보여줍니다.

**Open API / 자료 접근:** 설명 다음에 명확한 진입 경로를 제공하고, 개발자 문서·데이터 접근처럼 목적을 구분해 표시합니다.

## 12. 문장과 레이블 작성

- 지역어 표현은 표준어 풀이, 사용 지역, 자료 출처를 가능한 범위에서 함께 제공합니다.
- 메뉴와 버튼은 명사 나열보다 사용자의 다음 행동을 드러냅니다.
- 분류용 영문은 보조 레이블로만 사용하고, 한국어 정보보다 시각적으로 앞서지 않게 합니다.
- 한 문단에는 한 가지 메시지를 담고, 긴 설명은 목록이나 소제목으로 나눕니다.
- 데이터 기준일과 조사 맥락은 생략하지 않습니다.

## 13. 구현 참고

v4 메인 페이지의 범위 클래스와 토큰을 우선 활용합니다. 전역 CSS에 새 토큰이나 컴포넌트를 추가하기 전에는 공통 헤더, Footer, 로그인·마이페이지 등 기존 화면에 미치는 영향을 확인합니다.

```css
/* 새 v4 섹션에서 기존 토큰을 재사용 */
.section {
  color: var(--v4-ink);
  background: var(--v4-white);
  border-top: 1px solid var(--v4-line);
}

.section__title {
  font-family: var(--v4-font);
  font-size: clamp(2.125rem, 3.2vw, 3rem);
  font-weight: 600;
  line-height: 1.42;
  letter-spacing: -0.052em;
}
```

`index_v4.css`는 `.v4-main` 범위에 스타일을 적용하고 있습니다. 새 리뉴얼 스타일도 페이지 전용 루트 아래에 범위를 한정해 기존 화면과 충돌을 줄입니다.
