# 지역어 종합 정보 메인 리뉴얼

## 레퍼런스 분석

참고: https://www.mathflat.com/ (2026-09-17 확인)

매쓰플랫 메인은 큰 핵심 메시지와 주요 행동 버튼으로 시작하고, 대표 기능 소개, 솔루션 안내, 데이터 규모, 사례, 마지막 행동 유도 순서로 서비스를 설명한다. 재생/정지 및 이전/다음 컨트롤을 제공하고, 정보 전체를 한 번에 나열하기보다 스크롤 흐름에 따라 구분한다.

지역어 사이트에서는 이 정보 전달 방식을 다음과 같이 재해석했다.

- 첫 화면: 한글·지도·소리를 주제로 한 3개의 슬라이드와 각각의 서비스 바로가기.
- 검색: 통합 검색과 추천 검색어를 별도 영역에 배치.
- 서비스 소개: 지도, 목소리, 문학을 이미지 중심의 3개 카드로 설명.
- 탐색: 기존 지역어 기상도, 세대별 변화, 문학, 생활 자료를 4개 탭으로 제공.
- 참여: 나만의 지역어 지도 제작으로 연결.
- 기록과 활용: 기존 조사 통계 및 Open API / 자료실 연결.

디자인은 화이트와 선명한 블루, 여유 있는 간격, 큼직한 제목, 투명 소재의 3D 이미지로 구성했다. 레퍼런스의 로고, 사진, 문구, 코드를 복제하지 않았다.

## 이미지

생성 도구: 내장 GPT IMAGE (`image_gen`). 5개 이미지를 각각 별도로 생성했다.

원본 및 웹용 파일: `assets/renewal-2026/`

1. `hero-language`: 한글 조형물과 말풍선. 첫 슬라이드.
2. `hero-map`: 접힌 지도와 위치 표시. 두 번째 슬라이드 및 지도 소개 카드.
3. `hero-sound`: 헤드폰과 음성 파형. 세 번째 슬라이드 및 음성 소개 카드.
4. `archive-literature`: 책과 한글. 문학 소개 카드.
5. `archive-discovery`: 돋보기와 한글 카드. 나만의 지도 참여 섹션.

각 원본 PNG를 보존하고, WebP 변환본을 웹에서 사용한다. 5개 WebP 합계는 약 316 KiB다. 이 이미지는 장식·서비스 소개용이며 실제 조사 자료로 표시하지 않는다. 기존 생활 자료 탭의 조사 사진과 데이터는 유지한다. 시골 풍경이나 노년층 인물 이미지는 생성하지 않았다.

전체 생성 프롬프트: `assets/renewal-2026/prompts.json`

## 동작 및 접근성

- 히어로: 6.5초 간격 자동 전환, 이전/다음, 직접 선택, 재생/정지, 좌우 방향키, 모바일 스와이프.
- 마우스를 올리거나 키보드 포커스가 들어오면 전환을 일시 중단. 히어로가 화면 밖이거나 브라우저 탭이 숨겨진 경우에도 중단.
- 비활성 슬라이드는 `inert`와 `aria-hidden`으로 키보드 탐색에서 제외.
- 데이터 탭: 방향키 및 Home/End 지원, 선택 상태와 패널 연결 정보 제공.
- 스크롤: 실제 페이지 스크롤을 가로채지 않고 이미지 패럴렉스, 지역어 띠 이동, 요소 등장 및 통계 카운트업만 적용.
- `prefers-reduced-motion` 설정 시 자동 재생을 기본 중지하고 스크롤 애니메이션을 제거.
- 공통 `gnb.js`, `footer.js`, `styles.css`는 수정하지 않았다.

## 변경 파일

- `index_v2.html`: 콘텐츠, 이미지, 슬라이드 및 서비스 구성.
- `index_v2.css`: 메인 페이지 전용 반응형 디자인.
- `index_v2.js`: 슬라이드, 탭, 스크롤 인터랙션.
- `assets/renewal-2026/`: 이미지 원본, 최적화본, 생성 프롬프트.

검색 결과 처리 및 조사 데이터는 기존 서비스에 연결한다. 정적 서버에서는 기존 설문 기능의 정적 시연본으로 대체된다.

## 2026-09-30 v2 개선

- 본문 글자는 반응형 규칙까지 최소 14px로 정리하고 사용자 지정 Pretendard/시스템 폰트 스택을 적용했다. 공통 GNB·Footer와 설문 팝업은 변경하지 않았다.
- 히어로와 우측 자료 배너는 하나의 6.5초 재생 타이머를 공유한다. 어느 정지 버튼으로도 둘을 함께 멈추며, 페이지 직접 선택은 각 배너에 적용된다. 제어 버튼의 선택 영역은 최소 44×44px다.
- 사용자가 선택한 `about_coverage.html` 기준으로 통계를 통일했다. 국내 조사 기간 2004–2020년, 국내 155지점, 국외 10지점(2007–2011년), 수록 항목 237,495개, 국내 9개 권역이다. 항목 수는 국내 61지점·국외 10지점의 수록 범위임을 별도로 밝혔다. 수치는 바로 최종값을 표시한다.
- 서비스 카드의 예시는 기존 서비스에서 확인한 내용을 사용했다: `dialect_map.html`의 ‘가을’ 분포 지도 캡처, `vocab_dialect.html`의 지역어 ‘감자’와 표준어 ‘고구마’ 대응, `oral_dialect.html`의 강원도 삼척시 2004년 조사 전사문, `literature_dialect.html`의 박경리 〈토지〉에 쓰인 ‘괴’ 항목. 기존 생성 이미지는 카드 배경의 보조 시각 요소로 사용했다.
- 지도 캡처는 `assets/renewal-2026/service-map-live.png`다. 전사문과 문학 항목의 지역·조사연도·출처는 해당 자료 페이지에 표시된 값이다.
- 삭제된 지도·세대별 변화·문학 미리보기 섹션에 연결된 미사용 OpenLayers 라이브러리와 인라인 스크립트를 제거했다.
- Open API 안내에는 실제 안내 페이지의 회원 인증·인증키 발급 절차를 설명하고, 일반 상태와 호버 상태 모두 버튼 대비를 유지했다.
- 실제 브라우저에서 데스크톱 정렬, 390px·320px 가로 넘침과 글자 크기, 두 배너의 연동 전환·정지, 방향키 선택, 이미지 로딩을 검증했다.

## 2026-09-30 서비스 카드 이미지 교체

- 사용자 요청에 따라 위의 자료 발췌 미리보기를 제거하고, 내장 GPT IMAGE로 새로 제작한 실사풍 이미지 4장으로 교체했다. 지도, 한글 색인 카드, 마이크·헤드폰, 책·만년필이 각 서비스를 표현한다.
- 아이보리 종이, 파란 패브릭, 은은한 세이지 색감과 자연광으로 이미지의 분위기를 통일했다. 인물이나 시골 풍경은 사용하지 않았다. 실제 조사 사진이나 조사 데이터가 아닌 서비스 소개용 상징 이미지다.
- 카드 사진은 3:2 비율로 채우며, 제목·설명·바로가기는 이미지 아래에 배치한다. 호버와 키보드 포커스에서 사진을 1.035배로 부드럽게 확대한다.
- 원본 PNG, 웹용 WebP 및 전체 생성 프롬프트는 `assets/renewal-2026/service-cards-v2/`에 보관한다. WebP 4장 합계는 약 761 KiB다.
- 실제 브라우저에서 1440px 데스크톱과 390px·320px 모바일을 확인했다. 네 이미지 모두 정상 로딩되며 카드 영역 가로 넘침이 없고, 텍스트는 최소 14px를 유지한다. 공통 GNB·Footer 파일 및 설문 영역의 변경 없음도 확인했다.
- 서비스 섹션의 설명 문구는 데스크톱에서 제목 하단과 카드 영역 오른쪽 끝에 맞췄다. 1120px 이하에서는 제목 아래 왼쪽으로 이어지며, 1440px·820px·390px 화면에서 정렬과 가로 넘침 여부를 확인했다.
- 사용자 요청에 따라 히어로 페이지 표시를 축소했다. 선택 막대는 38px에서 22px, 기본 점은 8px, 점 중심 간격은 30px로 정리했다. 페이지 버튼의 클릭 영역은 30×44px, 재생 버튼은 44×44px를 유지하며 우측 자료 배너도 같은 표시 규격을 적용했다. 데스크톱·모바일과 클릭·방향키 선택을 확인했다.

## 2026-09-30 검색창 아래 배너 교체

- 우측 배너의 기존 3개 서비스를 요청한 지역어 기상도와 세대별 지역어변화 2개로 교체했다. 문구는 사용자가 제공한 내용이며 각각 `dialect_gisangdo.html`과 `dialect_wordcard.html`로 연결한다.
- 내장 GPT IMAGE로 심플한 투명 배경 일러스트 2장을 새로 제작했다. 기상도는 해·구름·지도·말풍선, 세대별 변화는 서로 다른 세대의 대화로 표현한다. 민트·연한 파랑의 단색 배경에 문구와 일러스트를 나란히 배치했다. 좌측 큰 배너의 이미지를 재사용하지 않는다.
- 원본 PNG, 투명도를 보존한 WebP 및 전체 제작 프롬프트는 `assets/renewal-2026/quick-illustrations-v1/`에 보관한다. 서비스 소개용 상징 그림이며 실제 조사 데이터로 표시하지 않는다.
- 1440px 데스크톱과 820px·390px·320px에서 이미지 로딩, 문구 잘림, 컨트롤 겹침, 가로 넘침을 확인했다. 두 페이지 선택과 방향키 순환도 확인했다. 공통 GNB·Footer와 설문 영역은 변경하지 않았다.
- 6.5초 자동 전환과 우측 정지 버튼으로 두 배너가 함께 멈추는 동작을 실제 브라우저에서 확인했다.

## 2026-09-30 서비스 카드 픽셀 호버

- 사용자가 제시한 https://locomotive.ca/en/work 의 목록 호버 이미지 미리보기를 실제 브라우저에서 확인하고, 기존 네 서비스 카드의 이미지 영역에 픽셀에서 선명한 사진으로 바뀌는 효과를 적용했다.
- 원본 사진 위에 Canvas 모자이크를 표시한다. 약 850ms 동안 픽셀 크기를 줄인 뒤 원본 사진을 보여주며, 추가 라이브러리나 새 이미지를 사용하지 않는다. 카드 글자와 링크는 계속 선명하게 유지한다.
- 마우스를 떼거나 화면 크기가 바뀌거나 브라우저 탭이 숨겨지면 효과를 중단한다. 키보드 포커스에서도 작동하며, 터치 입력과 동작 줄이기 설정에서는 기본 사진을 바로 보여준다.
- 문학 카드 WebP의 첫 로딩 오류를 보완하기 위해 같은 PNG 원본의 최적화 JPEG를 웹 표시용으로 사용한다. 원본과 기존 WebP는 보존했다.
- 실제 브라우저에서 큰 모자이크 프레임, 선명한 사진으로 전환, 빠른 마우스 이탈 시 취소, 키보드 포커스, 터치 입력 및 동작 줄이기 설정을 확인했다. 네 사진 모두 정상 로딩되며 JavaScript 문법 검사도 통과했다.
