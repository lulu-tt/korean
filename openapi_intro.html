국립국어원 지역어 종합 정보에 구축된 어휘 조사 자료를 Open API로 제공합니다.
인증키만 있으면 검색·연구·교육·서비스 개발에 지역어 데이터를 자유롭게 활용할 수 있습니다.

01

지역어 어휘 정보 Open API란?

지역어 Open API는 지역어 종합 정보 플랫폼의 어휘 데이터를 외부에 공개하여, 개발자와 연구자가 다양하고 유용한 서비스·애플리케이션을 만들 수 있도록 돕는 프로그램 인터페이스입니다.

조사 현장에서 채록한 지역어 표기, 대응 표준어, 조사 지역·연도·제보자 정보 등 양질의 사전·조사 정보를 개인 또는 기관에서 프로그램으로 불러와 활용할 수 있습니다.

오픈 API란?
웹 사이트나 서비스가 가진 기능을 외부에서도 호출할 수 있도록 공개한 프로그래밍 인터페이스입니다. 정해진 주소(URL)와 파라미터로 요청하면 JSON 형식의 결과를 받을 수 있습니다.
02

무엇을 할 수 있나요?

어휘 검색 연동

검색어·지역·연도·연령·성별 조건으로 지역어 어휘를 조회하고 서비스에 바로 붙일 수 있습니다.

연구·교육 활용

지역·세대별 언어 변이 연구, 교육 콘텐츠·사전 보조 자료 등 학술·교육 목적에 활용할 수 있습니다.

앱·웹 서비스 개발

지도, 퀴즈, 사전 확장 등 지역어를 주제로 한 애플리케이션과 웹 서비스를 구현할 수 있습니다.

03

이용 절차

1

회원 로그인

Open API는 회원 인증 후 이용할 수 있습니다. 비회원이라면 먼저 가입해 주세요.

2

인증키 발급

키 발급 메뉴에서 API 키를 신청·확인합니다. 유효하지 않은 키로는 호출할 수 없습니다.

3

API 호출

활용안내의 요청 URL·파라미터·응답 필드를 참고해 데이터를 조회합니다.

04

제공 데이터 개요

검색 요청 시 JSON 형식으로 결과 목록을 반환합니다. 요청 변수·응답 필드·상태 코드의 상세 명세는 활용안내 페이지에서 확인할 수 있습니다.

요청 URL (예시)

https://dialect.korean.go.kr/dialect/openAPI/data

주요 응답 항목

  • 지역어 · 대응 표준어
  • 조사 지역(시·도 / 시·군·구)
  • 조사 연도 · 출처
  • 제보자 연령 · 성별
파라미터·응답 명세 자세히 보기
05

이용 시 유의사항

  • Open API 이용에는 유효한 인증키(apiKey)가 필수입니다. 키가 없거나 잘못되면 서비스가 제한됩니다.
  • 인증키가 만료·분실되었거나 유효하지 않은 경우 키 발급 메뉴에서 재발급·재확인해 주세요.
  • 제공 데이터는 국립국어원 지역어 조사 자료에 기반하며, 서비스 정책에 따라 항목·제공 범위가 변경될 수 있습니다.
  • 과도한 호출은 서비스 안정성을 해칠 수 있으니, 필요 범위 내에서 이용해 주시기 바랍니다.
  • 이용 약관 및 저작권 정책을 준수해 주세요. 문의는 의견 제시 게시판을 이용해 주세요.
