국립국어원 지역어 종합 정보 시스템이 수집한 전국 토박이말 어휘 데이터를 Open API로 공개합니다.
인증키 하나로 학술 연구, 검색 서비스, 교육용 어플리케이션을 손쉽게 개발해보세요.

OVERVIEW

지역어 어휘 정보 Open API란?

지역어 데이터의 가치를 높이고 다양성을 보존하기 위해 프로그래밍 인터페이스로 제공합니다.

양질의 방언 데이터 자산 공개

지역어 Open API는 국립국어원 어휘 조사 결과물을 외부에 공개하여, 연구자 및 개발자가 유용한 애플리케이션을 연동 제작할 수 있도록 지원하는 프로그램 인터페이스입니다.

현장에서 체록한 방언 표기, 대응 표준어, 조사 시·도 및 시·군·구, 제보자 연령·성별 정보까지 사전적 가치가 높은 원자료를 직접 호출하실 수 있습니다.

Open API 개념

웹사이트 또는 서비스의 내부 기능을 외부에서 표준화된 규격(HTTP GET)으로 호출할 수 있도록 오픈한 데이터 창구입니다. 정해진 요청 URL과 파라미터를 넘기면 JSON 응답 형태로 데이터를 가져옵니다.

FEATURES & VALUE

무엇을 할 수 있나요?

어휘 검색 연동부터 학술 연구 및 웹/앱 서비스 개발까지 폭넓게 활용할 수 있습니다.

01

어휘 검색 연동

검색어, 조사 지역, 조사 연도, 제보자 연령·성별 조건을 조합하여 방언 어휘를 조회하고 자사 서비스에 실시간 연결합니다.

02

연구 · 교육 활용

지역별·세대별 우리말 변이 연구, 국어 교육 보조 교재 개발, 사전 콘텐츠 구축 등 다양한 학술·교육 목적에 활용합니다.

03

앱 · 웹 서비스 개발

지역어 지도, 방언 퀴즈 게임, 디지털 사전 등 우리말을 주제로 한 다양하고 세련된 신규 서비스를 직접 구현합니다.

WORKFLOW

간편한 3단계 이용 절차

회원가입 후 인증키 발급부터 API 연동까지 빠르고 명확하게 진행됩니다.

1

회원 로그인

Open API 서비스는 회원 인증 후 이용이 가능합니다. 아직 계정이 없다면 회원가입을 먼저 완료해 주세요.

2

인증키 발급

키 발급 메뉴에서 사용 목적 및 URL을 입력하고 30자 고유 인증키를 즉시 부여받습니다.

3

API 데이터 호출

활용안내의 파라미터 규격을 확인하고 테스트베드에서 직접 응답 데이터를 검증합니다.
