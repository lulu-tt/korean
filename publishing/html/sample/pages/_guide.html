No Data / Empty State

Board — 등록된 게시물 없음 (테이블 내부 삽입)
번호 분류 제목 첨부 등록일 조회

등록된 게시물이 없습니다.

추후 게시물이 등록될 예정입니다.

<div class="board-no-data"> <div class="no-data no-data--board"> <div class="no-data__icon">...svg...</div> <p class="no-data__text">등록된 게시물이 없습니다.</p> <p class="no-data__sub">추후 게시물이 등록될 예정입니다.</p> </div> </div>
Search — 검색 결과 없음 (검색어 피드백 포함)
번호 제목 등록일 조회

'검색어'에 대한 검색 결과가 없습니다.

다른 검색어를 입력하거나 조건을 변경해 보세요.

Gallery — 등록된 사진 없음

등록된 사진이 없습니다.

포토갤러리가 업데이트되면 이곳에 표시됩니다.

Error — 데이터 로드 실패 / 시스템 오류

데이터를 불러오지 못했습니다.

일시적인 오류입니다.
잠시 후 다시 시도해 주세요.

인터넷 연결 후 다시 시도해 주세요.

Slider / Pause Pattern

일시정지·재생 버튼 공통 패턴

모든 슬라이더(히어로, 팝업존, 배너존, 카드뉴스, 롤링배너)에서 동일 패턴 사용. 버튼에 .is-paused 클래스 토글로 아이콘 전환.

HTML
<!-- 일시정지 버튼: aria-label은 JS가 syncPauseUI()로 업데이트 --> <button class="[컴포넌트]-toggle" type="button" aria-label="자동재생 일시정지"> <!-- 재생 중 표시 --> <svg class="si-pause" ...>pause icon</svg> <!-- 일시정지 중 표시 --> <svg class="si-play" ...>play icon</svg> </button>
CSS
/* 기본: pause 아이콘 표시, play 아이콘 숨김 */ .si-play { display: none; } /* .is-paused 상태: 반전 */ .is-paused .si-pause { display: none; } .is-paused .si-play { display: inline; }
JS — ui.js 공통 함수
/* syncPauseUI: 버튼 상태 동기화 */ function syncPauseUI(btn, isPaused) { btn.classList.toggle('is-paused', isPaused); btn.setAttribute('aria-label', isPaused ? '자동재생 시작' : '자동재생 일시정지' ); } /* manualPaused 플래그: hover 일시정지와 분리 */ var manualPaused = false; toggleBtn.addEventListener('click', function () { manualPaused = !manualPaused; manualPaused ? pause() : play(); syncPauseUI(toggleBtn, manualPaused); }); wrap.addEventListener('mouseenter', function () { if (!manualPaused) pause(); // 수동 일시정지 중엔 hover 무시 }); wrap.addEventListener('mouseleave', function () { if (!manualPaused) play(); });
운영 데이터 슬롯 주석 규칙

JSP 이식 시 개발파트(CODEX)가 슬롯 위치를 찾을 수 있도록 HTML에 주석으로 표기.
