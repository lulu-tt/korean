공지사항 — 개발 이식 상태 참조

이 페이지는 개발 이식 기준 엣지케이스 참조용입니다. 실제 서비스에는 노출되지 않으며, JSP 조건 분기에 따라 렌더되는 각 빈 상태 UI를 사전 확인하기 위한 목적으로 사용합니다.
상태 1 — 첨부파일 없음 (attach 블록 미렌더)
<c:if test="${fn:length(attachList) gt 0}"> <div class="board-detail__attach"> ... </div> </c:if> → attachList가 비어 있으면 .board-detail__attach 블록 자체를 렌더하지 않음

첨부파일이 없는 게시물 예시

작성자 관리자 등록일 2025.04.15 조회수 128

첨부파일이 없는 게시물의 경우 .board-detail__attach 블록 전체가 렌더되지 않습니다.

본문 콘텐츠 영역은 정상적으로 표시됩니다.

목록
상태 2 — 첨부파일 있음 (정상 렌더 비교)
파일명 / 용량: ${attach.orignlFileNm} (${attach.fileSize}KB) 다운로드 URL: /cmm/fms/FileDown.do?atchFileId=${attach.atchFileId}&fileSn=${attach.fileSn}

상태 3 — 이전글 / 다음글 없음 (케이스별)
<c:choose> <c:when test="${prevArticle != null}"> <a class="detail-nav__item" href="..."> ... </a> </c:when> <c:otherwise> <span class="detail-nav__item detail-nav__item--none"> <span class="detail-nav__label">이전글</span> <span class="detail-nav__title">이전 게시물이 없습니다.</span> </span> </c:otherwise> </c:choose>
케이스 A — 이전글 없음 / 다음글 있음
이전글 이전 게시물이 없습니다. 다음글 디지털 행정서비스 개선 과제 공모 결과 발표 2025.04.18
케이스 B — 이전글 있음 / 다음글 없음
이전글 사업 참여 신청서 제출 기한 연장 안내 2025.04.10 다음글 다음 게시물이 없습니다.
케이스 C — 이전글 / 다음글 모두 없음 (단일 게시물)
이전글 이전 게시물이 없습니다. 다음글 다음 게시물이 없습니다.
케이스 D — 이전글 / 다음글 모두 있음 (정상)
이전글 사업 참여 신청서 제출 기한 연장 안내 2025.04.10 다음글 디지털 행정서비스 개선 과제 공모 결과 발표 2025.04.18
상태 4 — 목록 0건 (게시판 목록 empty state)
<c:choose> <c:when test="${fn:length(resultList) == 0}"> <div class="no-data no-data--board"> ... </div> </c:when> <c:otherwise> <!-- 일반 테이블 렌더 --> </c:otherwise> </c:choose> 검색 결과 0건과 데이터 자체 없음은 동일 컴포넌트를 사용하며, 텍스트만 조건부로 변경합니다. 데이터 없음: "등록된 게시물이 없습니다." 검색 결과 없음: "검색 결과가 없습니다."
케이스 A — 데이터 없음

등록된 게시물이 없습니다.

현재 등록된 공지사항이 없습니다. 나중에 다시 확인해 주세요.

케이스 B — 검색 결과 없음

검색 결과가 없습니다.

검색어를 다시 확인하거나 다른 조건으로 검색해 보세요.

클래스 레퍼런스
클래스 엘리먼트 설명
.board-detail__attach div 첨부파일 영역 — attachList.size() > 0 일 때만 렌더
.detail-nav__item a 이전/다음글 링크 — 게시물이 존재할 때
.detail-nav__item--none span 이전/다음글 없음 상태 — pointer-events:none, 회색 표시
.no-data--board div 게시판 목록 0건 상태
.no-data--search div 검색 결과 없음 상태
