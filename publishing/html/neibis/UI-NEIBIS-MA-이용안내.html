기술지원 관련 FAQ

  • 아래와 같이 기본서비스, 유지보수 계약 시 2가지로 나누어 집니다. 혜택을 비교해 보세요.

    • 1.기본 지원(무료)

      아래 사항을 기본적으로 지원해 드립니다.

      • 개발자 가이드, 매뉴얼 제공
      • 제품 구매 후 1년 이내 장애 조치 및 보안 업데이트 지원
    • 2.유지보수 계약 시(견적상담 후 요금 책정)

      유지보수 계약시 아래 사항을 기본적으로 지원해 드리며 추가혜택을 제공드립니다.

      • 개발자 가이드, 매뉴얼 제공
      • 제품 구매 후 1년 이내 장애 조치 및 보안 업데이트 지원
      추가혜택은 아래와 같습니다.
      • 전담 고객지원 PMS 채널 개설 후 신속한 문제 해결 지원
      • 계약 비용에 맞는 신규 기능 추가, 개선 지원
      • 네이비스 버전 업그레이드

  • 기술 지원 문의부터 해결까지 간편하게 온라인으로 의사소통할 수 있습니다.
    자세한 과정은 아래에서 확인하실 수 있습니다.

    1. 1.인시퀀스 PMS를 통해 문의사항을 등록해주세요. PMS가 무엇인가요?

      Git 기반 온라인 의사소통 시스템 입니다.
      PMS를 통해 게시물을 등록할 수 있으며 이슈를 문의할 수 있습니다.

      PMS 요청 가이드 문서 보기
    2. 2.인시퀀스에서 문의사항을 확인 후 담당자를 배정해드립니다.

      이슈를 확인 후 담당자를 배정하며 내용을 면밀히 검토합니다.

    3. 3.이슈 작업을 진행하게 됩니다.
      • 고객과의 커뮤니케이션을 통해 문제 해결을 도와드립니다.
      • 버그, 이용법, 기타문의 다양한 주제로 이슈를 등록하실 수 있습니다.
      PMS로 작업물을 전달드리며 이메일로 알림을 받을 수 있습니다.
    4. 4.작업물을 확인해주시면 됩니다.

      최종적으로 요구사항이 잘 반영되었는지 확인해주신 후 문제가 없다면 이슈를 종료하게 됩니다.

    온라인 의사소통 과정이 더 궁금하시다면 아래 버튼을 클릭해 자세한 과정이 담긴 스토리를 확인하실 수 있습니다. 더 자세한 내용 보러가기
