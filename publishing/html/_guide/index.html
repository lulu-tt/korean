버튼 (Button)

Type 사용자 과업, 플로우의 중요도에 따라 버튼 간 위계를 구분하여 사용한다.

Size 콘텐츠 내에서 적합한 계층을 가진 크기로 사용한다.

State 사용자의 상호작용 시 컬러가 변경된다 (실제로 마우스를 올리거나 눌러서 확인).

Icon 버튼 내에 시각적인 상징이 필요하다면 사용한다. 아이콘을 텍스트 앞/뒤 어디에 두느냐로 left/right가 정해진다.

아이콘 전용 버튼 (btn-icon)

아이콘 자체는 색을 바꾸지 않으므로(원본 svg 색 그대로), primary에서만 흰색으로 자동 반전된다.

아이콘 전용 버튼 + 툴팁 (tooltip)

버튼을 .tooltip로 감싸고 .tooltip-text를 추가하면 hover/focus 시 텍스트가 노출된다. .tooltip로 감싸지 않으면 위 아이콘 전용 버튼과 동일하게 동작한다.

안내 툴팁 버튼 (Tooltip Button)

라벨이나 th 텍스트 옆에 붙이는 20x20 크기의 독립된 안내 버튼이다. 버튼에 .tooltip-btn을 주고 ico-tooltip 아이콘과 .tooltip-layer를 함께 넣으면 hover 또는 키보드 포커스 시 안내 내용이 노출된다. .tooltip-layer 안에는 .tooltip-title(제목)과 .tooltip-item(항목)을 필요한 만큼 넣을 수 있다.

인풋 그룹 (input-group)

입력 필드 여러 개를 한 덩어리로 묶어서 배치할 때 사용한다. .input/.select는 수정하지 않고, 감싸는 wrapper에 .input-group을 붙인다.

input-group 인풋/셀렉트 + 버튼을 한 줄로 묶을 때 사용한다. 모바일에서는 버튼이 다음 줄로 내려간다.

첨부파일 (File Attach)

.input-group에 .file-attach-group을 함께 붙여 쓴다. 파일 input은 .sr-only로 숨기고, 버튼(.file-attach-btn)이 대신 클릭을 위임해 파일 선택창을 연다. 선택한 파일명은 .file-attach-name 표시용 인풋에 자동으로 채워진다. id 매칭이 아니라 .file-attach-group 컨테이너 기준으로 동작하므로, 이 블록을 그대로 복사해서 파일 input의 id/name만 겹치지 않게 바꾸면 한 페이지에 여러 개 둬도 된다.

※ 10MB 이하의 파일만 첨부할 수 있습니다.

보안문자 (Captcha)

.captcha-group은 보안문자 영역의 레이아웃만 담당한다. .captcha-code는 실제 캡차 이미지/오디오 위젯이 들어갈 자리표시자(placeholder)이며, 위젯 삽입·새로고침·음성듣기·검증 로직은 개발팀 영역이다. 퍼블에서는 이 블록을 그대로 복사해서 텍스트 입력(input)의 id/label for만 페이지에 맞게 바꿔 쓰면 된다.

보이는 순서대로 숫자 및 문자를 모두 입력해주세요

페이지 상단 이동 (Page top button)

스크롤을 내리면 노출되는 우측 하단 고정 버튼. 동작은 ui-global.js의 pageTopButton에서 처리한다.

<button class="page-top-button">

모달 (Modal)

네이티브 <dialog> 요소 기반. 호출 버튼에는 data-modal-open="#대상id", 닫기 버튼에는 data-modal-close 속성을 사용한다(직접 onclick 연결 금지). 제목은 aria-labelledby로 .popup-title과 연결해야 한다. 열림/닫힘 포커스 이동, 배경 스크롤 잠금, Esc 닫기, 배경(backdrop) 클릭 닫기는 ui-global.js의 modal이 전부 처리한다.

Size 클래스 없음 = modal-md(기본값)와 동일. modal-sm / modal-md / modal-lg로 크기를 조절한다.

Small 모달

간단한 확인/알림 등 내용이 짧은 경우에 사용한다.

Medium 모달 (기본값)

별도 크기 클래스가 없으면 medium이 기본값이다.

Large 모달

표, 폼 등 내용이 많은 경우에 사용한다.

Footer 확인/취소 등 액션이 필요하면 popup-footer에 btn-group을 넣는다.

삭제 확인

선택한 항목을 삭제하시겠습니까? 삭제한 내용은 복구할 수 없습니다.

얼럿 / 컨펌 (Alert / Confirm)

확인이 꼭 필요한 짧은 안내/확인 메시지에는 마크업을 직접 만들지 않고 uiAlert() / uiConfirm() 함수를 호출한다. 일반 모달과 달리 배경(backdrop) 클릭이나 Esc로 닫히지 않는다 — 반드시 버튼을 눌러야 닫힌다(실수로 취소/확인되는 것을 방지하기 위함). 제목/아이콘 없이 메시지만 넘기면 기본형, { icon, title, message } 객체를 넘기면 확장형이다. 

// 기본형: 메시지만
uiAlert("저장되었습니다.");
uiConfirm("삭제하시겠습니까?", function (result) {
  if (result) { /* 확인 */ } else { /* 취소 */ }
});

// 확장형: 제목 + 아이콘까지 (icon: info(기본값) / success / warning / error / "none")
uiAlert({ icon: "success", title: "저장 완료", message: "정상적으로 저장되었습니다." });
uiConfirm(
  { icon: "warning", title: "회원 탈퇴", message: "정말 탈퇴하시겠습니까?<br>탈퇴 후에는 복구할 수 없습니다." },
  function (result) { ... }
);

※ 탭 패널의 활성화(선택) 상태 제어에는 .is-active 클래스를 사용합니다.

※ 토글 버튼은 .is-active, 토글 대상 콘텐츠의 열림 상태 제어에는 .is-open 클래스를 사용합니다.
