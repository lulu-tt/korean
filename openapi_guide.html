Open API 활용안내

소개 키 발급 활용안내

지역어 어휘 정보 Open API 연동을 위한 요청 URL · 파라미터 · 응답 필드 · 상태 코드를 안내합니다.
아래 테스트베드에서 조건을 넣어 요청 URL·샘플 응답·호출 코드를 바로 확인할 수 있습니다.

01

이용 개요

지역어 Open API는 조사·구축된 지역어 어휘 정보를 JSON으로 제공합니다. 서비스 이용 전 인증키 발급이 필요하며, 모든 요청에 apiKey와 검색어를 포함해야 합니다.

REQUEST URL https://dialect.korean.go.kr/dialect/openAPI/data
전송 방식은 GET 쿼리 파라미터 방식입니다. 브라우저 주소창 테스트 또는 서버·클라이언트 HTTP 요청으로 호출할 수 있습니다.

03

검색 출력 결과 필드 (Response field)

resultList 배열의 각 항목에 포함되는 필드입니다.

Open API 응답 필드

04

응답 결과 (Response Result)

Open API 응답 결과 키

          · 현재 페이지: 발급 키(localStorage) 자동 반영 + 모의 JSON 응답으로 연동 흐름 검증
